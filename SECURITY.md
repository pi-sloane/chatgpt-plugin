# Security

We appreciate responsible reports that help keep Pi Security and its users safe.

## Report a vulnerability privately

Please do not disclose suspected vulnerabilities in a public issue, discussion, pull request, or screenshot.

Email [contact@pi.security](mailto:contact@pi.security) with the subject **Security report: ChatGPT plugin**. Start with a brief description of the affected feature and potential impact. We will help arrange a secure way to share any sensitive supporting material.

Do not send credentials, access tokens, secrets, customer data, personal data, exploit code, or production logs until a secure transfer method has been agreed upon.

If information was accidentally published, remove it where possible, rotate any exposed credentials, and tell us about the exposure in your private report.

For general questions or product support, visit [pi.security](https://www.pi.security/) or email [contact@pi.security](mailto:contact@pi.security).
